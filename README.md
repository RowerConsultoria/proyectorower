# Proyecto Rower — Informe y aplicativo web

Repositorio del **Proyecto Rower**: consultoría de Optimización Organizacional y Adopción de IA de **UCAB Consultores** para **Grupo Kenex**. Aquí vive el informe navegable, el panel administrativo y el prototipo `/sistema`.

> ⚠️ **Contenido confidencial.** Material interno del equipo consultor. No compartir fuera del equipo sin autorización de la PM (Clemencia Abad).

## Para trabajar en este repositorio

- **[`CLAUDE.md`](CLAUDE.md)** — arquitectura del aplicativo, convenciones obligatorias, flujo de trabajo. Léelo antes de tocar cualquier cosa.
- **[`BITACORA.md`](BITACORA.md)** — el avance del proyecto, único registro. **Actualizarla es obligatorio antes de todo `git push`** — el procedimiento está en el propio archivo.

## Local (Windows)

```bash
git clone https://github.com/RowerConsultoria/proyectorower.git
```

Doble clic en `scripts/servidor-local.bat` → `http://localhost:8080`. Para mantenerte al día con GitHub: `scripts/sincronizar.bat` (manual) o `scripts/auto-sincronizar.ps1` (cada 5 min).
